# FitLog

 FitLog is a workout tracking web app that lets users explore exercises, create daily workout plans, save routines, and track total duration and burned calories.

## Tech Stack
* Next.js
* React
* TypeScript
* Tailwind CSS
* React Icons

## Features
1. **Exercise Library:** View exercises with details like duration, calories, and equipment.
2. **Daily Plan:** Add exercises to today's plan to manage your daily workout routine.
3. **Saved Workouts:** Save favorite workouts and sort them by duration, calories, or rating.
4. **Stats Tracker:** Calculates total workouts, total time, and calories for your plan.
5. **Responsive Dark UI:** Clean dark-mode interface with toast alerts and empty states.
